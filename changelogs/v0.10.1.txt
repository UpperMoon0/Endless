Endless 0.10.1

- Capture immutable sparse block palettes in a bounded camera vicinity once per vanilla render chunk on Minecraft 1.20.1 and 1.21.1, avoiding synchronized world lookups for each meshing block read. Preserve live block-entity discovery, distant-query fallback and normal rebuild invalidation.
- Add a production-client FPS comparison against vanilla, Fabric alone, and Endless 0.10, with frame-time tails, native framebuffer checks, and local-only raw results.
- Add a bounded vertical render-section budget with tall-structure Create and Complementary compatibility.
- Index sparse POI sections by column so ordinary chunk unloads do not scan unrelated dense terrain storage.
- Reuse bounded per-solve skylight opacity samples and stop rays at their proven maximum, avoiding repeated block reads while preserving light attenuation.
- Restore reloaded 26.1.2 POI sections to their sparse column index so searches and subsequent saves retain them.

- Add bounded vertical terrain LOD: 4,096 blocks of total vertical view by default with a separate 512-block detailed window. Both spans remain configurable up to 8,192 blocks; set verticalLodSections to zero to disable simplified terrain. Cache reduced static block geometry with revision invalidation, horizontal fog/distance handling, independent far depth and native foreground occlusion.
